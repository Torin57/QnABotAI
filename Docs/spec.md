# Спецификация (SDD): Семантический FAQ-бот с админкой на Next.js

## 1. Описание проекта
Telegram-бот, который отвечает на вопросы студентов, используя базу знаний (FAQ). 
Бот НЕ генерирует ответы "из головы". Он использует векторную БД только для поиска наиболее подходящего заготовленного ответа (семантический роутинг). 
Интерфейс преподавателя для работы с неотвеченными вопросами реализован в виде веб-приложения на Next.js. Весь проект реализован в едином стеке на TypeScript/Node.js.

## 2. Стек технологий (Fullstack TypeScript)
- **Telegram Бот:** Node.js, библиотека `Gram.js` (или `grammY` / `telegraf`).
- **Фронтенд и Бэкенд админки:** `Next.js` (App Router, React, TailwindCSS).
- **База данных логов:** `SQLite` + **`Drizzle ORM`** (легковесная ORM для работы с БД).
- **Векторная БД:** Qdrant (используем `@qdrant/js-client-rest`, локальный режим хранения в файлах, без Docker).
- **Эмбеддинги:** API Mistral (используем `@mistralai/mistralai`, модель `mistral-embed`).
- **Окружение:** `dotenv` для ключей.

## 3. Архитектура и логика
1. **База FAQ:** Хранится в файле `faq.json` (массив объектов с полями `question`, `answer`).
2. **Инициализация:** Отдельный скрипт (или API-роут) читает `faq.json`, векторизует вопросы через Mistral API и складывает в Qdrant. Текст ответа сохраняется в payload вектора.
3. **Обработка сообщения (Бот):** 
   - Пользователь пишет вопрос.
   - Бот векторизует текст пользователя через Mistral.
   - Выполняется поиск по Qdrant. 
   - Если `score` (уровень совпадения) > 0.8: бот выдает ответ из payload.
   - Если `score` < 0.8: бот отвечает "Не нашел ответа", выдает Inline-кнопку "Связаться с преподавателем".
4. **Логирование:** Вопросы со `score` < 0.8 записываются в SQLite через Drizzle ORM в таблицу `unanswered_queries` (поля: id, user_id, question_text, timestamp).
5. **Админка (Next.js):** 
   - Серверные компоненты Next.js читают таблицу `unanswered_queries` через Drizzle ORM.
   - На веб-странице выводится удобная таблица с вопросами, на которые бот не смог ответить.

## 4. Структура репозитория (Единый проект Next.js)
- `/src/bot` — логика Telegram-бота (роутеры, обработчики).
- `/src/app` — страницы и API-роуты админки Next.js.
- `/src/db` — схемы Drizzle ORM и настройки подключения к SQLite.
- `/src/lib/qdrant` — настройка локального Qdrant-клиента.
- `logs.db` — файл базы данных SQLite (в корне).
- `.env` — ключи (TG_BOT_TOKEN, MISTRAL_API_KEY).

## 5. Требования к безопасности
- Строго использовать `.env` для всех секретов.
- Файлы `.env`, `logs.db`, `qdrant_data/`, `node_modules/`, `.next/` должны быть добавлены в `.gitignore`.
